# Enoove — Premium Digital Agency Website

> **"We transform businesses through intelligent digital experiences, creative design, and smart automation."**
> **"نصنع تجارب رقمية ترتقي بأعمالك"**

An award-caliber digital agency website built with **React 19**, **Vite**, **TypeScript**, and an advanced **Glassmorphism Design System** featuring 3D spatial showcases, interactive neural workflow simulators, and real-time ERP dashboards.

---

## 🌟 Key Highlights & Features

- **Spatial 3D Website Showcase Slider:**
  - True 3D perspective layering (`perspective: 1400px`, `rotateY`, `translateZ`) inspired by spatial glass interfaces.
  - Showcases 5 core industries: Luxury Restaurant, Medical Clinic, Travel Agency, Real Estate, and Haute E-Commerce.
  - Floating controller pill with direct thumbnails, live dot indicators, and autoplay with pause-on-hover.

- **Autonomous AI & Smart Systems Ecosystem:**
  - Central glass neural engine with animated connected nodes.
  - Live interactive customer journey simulator (WhatsApp webhook → AI qualification → automated booking → CRM sync).

- **Cloud Enterprise & Business Systems (ERP/SaaS):**
  - Interactive multi-tab cockpit (Finance & P&L, Inventory telemetry, and CRM).
  - High-precision telemetry charts and live KPI counters.

- **Creative Studio & Brand Identity:**
  - High-end masonry gallery with 3D mockups (Logos, unboxing perfume packaging, storefront facades, and 3D social campaigns).

- **Bilingual & Responsive Excellence:**
  - Full Arabic (RTL) & English (LTR) language context with instant switching.
  - Tailored typography with `@fontsource/cairo` and `Plus Jakarta Sans`.
  - Fully responsive across desktop, tablet, and mobile.

---

## 🛠️ Technology Stack

- **Framework:** React 19 + TypeScript
- **Bundler & Dev Server:** Vite 8
- **Typography:** Cairo Arabic & Plus Jakarta Sans
- **Styling:** Custom Glassmorphism CSS System with Deep Midnight (`#080B14`), Electric Blue (`#647BFF`), and Cyan (`#40D9E8`)
- **Version Control:** Git & GitHub (`mohob12/Enoove`)

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/mohob12/Enoove.git

# Navigate to project
cd Enoove

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
